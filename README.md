# esports-ranking-analyzer
Sistema de análise de desempenho de algoritmos de ordenação aplicado a rankings de jogadores de E-sports.

## Objetivo

Desenvolver um sistema em Java capaz de organizar dados de jogadores utilizando diferentes algoritmos de ordenação e comparar o desempenho de cada algoritmo através do tempo de execução.

## Algoritmos

- Bubble Sort
- Insertion Sort
- Merge Sort

## Dados

Cada jogador poderá possuir:

- Nome
- Pontuação
- Vitórias
- Derrotas
- K/D

Os dados poderão ser:
- Gerados Aleatoriamente pelo sistema;
- Importados através de arquivos `.txt`.

## Benchmark

O sistema deverá medir exclusivamente o tempo utilizado pelos algoritmos durante o processo de ordenação.

O tempo de geração ou aquisição dos dados não será contabilizado.
